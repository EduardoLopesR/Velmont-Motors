# Velmont Motors

O objetivo deste projeto é desenvolver um sistema para uma concessionária de veículos de luxo, oferecendo uma plataforma moderna e fácil de utilizar. Utilizando tecnologias do php como o phpMailler localizado na pasta com o mesmo nome, com objetivo acadêmico na Proz de fazer um teste de documentação de software.
